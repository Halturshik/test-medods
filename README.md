Реализована поддержка периодических задач.

Задачи разделены на:

- **родительскую задачу (шаблон)**
- **дочерние экземпляры (инстансы)**

---

При создании задачи с настройкой повторения генерируются дочерние экземпляры в пределах **60 дней**.

Это выбранный баланс между:
- удобством пользователя (видимость задач наперёд)
- ограничением роста количества записей в базе данных

---

Дочерние задачи сохраняются как отдельные записи с привязкой к шаблону через `parent_id`.

---

Дополнительно реализован worker, который периодически:

- выгружает шаблоны задач
- проверяет уже созданные экземпляры
- досоздаёт недостающие задачи до горизонта в 60 дней

---

Учтены сценарии завершения повторяющихся задач:

- `never` — без ограничений по времени
- `by_date` — генерация прекращается после указанной даты
- `by_count` — генерация ограничена максимальным количеством экземпляров

---

Пользователь всегда видит задачи в пределах **60 дней**,  

при этом фактический горизонт может быть меньше, если:
- задана дата окончания (`by_date`)
- или достигнуто максимальное количество повторений (`by_count`)

Таким образом система генерирует только необходимый объём данных и избегает избыточного хранения задач.
